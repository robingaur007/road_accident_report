# Road Accident Analysis Dashboard 

## Background
This project was developed as part of the evaluation process for the IISc Bangalore ISTUP Internship, where it was shortlisted for Round 2.

This project presents a comprehensive **Road Accident Analysis Dashboard ** built in **Power BI**.  
The dashboard provides insights into accident trends, causes, vehicle involvement, casualties, and road safety indicators.

## Key Features
- Trend analysis of accidents over time  
- Breakdown by **vehicle type**, **location**, and **weather conditions**  
- Heatmaps for high-accident zones  
- Casualty and severity analysis  
- KPIs for road safety improvement  
- Fully interactive dashboard (Power BI)

## Purpose of the Project
This dashboard is designed to:
- Identify major accident causes  
- Support decision-making for road safety  
- Help authorities in policy planning  
- Provide a clear and interactive view for stakeholders
